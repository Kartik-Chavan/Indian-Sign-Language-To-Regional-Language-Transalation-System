API Documentation

Getting Started

Installation

git clone https://github.com/Kartik-Chavan/Indian-Sign-Language-To-Regional-Language-Transalation-System.git
cd Indian-Sign-Language-To-Regional-Language-Transalation-System
pip install -r requirements.txt

Requires Python 3.8+ and Git installed

Running the System

python main.py
Make sure all dependencies are installed first

API Endpoints

POST /detect

Process video frames for sign detection

{
  "frame": "base64_encoded_image",
  "language": "hindi",
  "threshold": 0.7
}

GET /languages

List supported translation languages

Configuration

Model Parameters

Adjust detection thresholds and language preferences

# config.py
DETECTION_THRESHOLD = 0.7
DEFAULT_LANGUAGE = "hindi"

Response Format

{
  "status": "success",
  "translation": "नमस्ते, आप कैसे हैं?",
  "confidence": 0.92
}

API Usage Guidelines

Maximum frame size: 1920x1080 pixels

Rate limit: 10 requests per minute

Always check response status codes
